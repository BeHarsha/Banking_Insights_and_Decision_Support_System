Banking Insights and Decision Support System
Description
This project is a data analytics and business intelligence solution built to analyze banking data and generate actionable insights. It uses Python for exploratory data analysis (EDA) and Power BI for interactive dashboard visualization of key banking metrics such as deposits and loans.

Objectives
Analyze banking data to identify trends and patterns
Understand loan and deposit distribution
Build dashboards for decision support
Perform data cleaning and preprocessing

Tech Stack
Python
Pandas, NumPy, Matplotlib, Seaborn
Power BI
Jupyter Notebook

Project Structure
Banking_Insights_and_Decision_Support_System/
│── Banking.csv
│── Banking.xlsx

│── EDA.ipynb

│── Images/

Installation
Clone the repository
git clone https://github.com/BeHarsha/Banking_Insights_and_Decision_Support_System
cd banking-insights
Install dependencies
pip install pandas numpy matplotlib seaborn
Open Jupyter Notebook
jupyter notebook

Usage
Open and run EDA.ipynb or Banking.ipynb for analysis
Open Banking Dashboard.pbix in Power BI Desktop to view dashboards
